📨 Request-Flow

1
Browser ruft https://up2daite.com auf
2
Traefik terminiert TLS (HTTPS → HTTP) und routet per Ingress-Regeln
3
Nginx im Frontend-Pod served die React-App
4
API-Calls (/api/*) werden an den Backend-Service geproxied
5
Spring Boot verarbeitet die Anfrage und greift auf PostgreSQL zu

🔒 Zertifikat-Flow

A
cert-manager beantragt Zertifikat bei Let's Encrypt (ACME)
B
Let's Encrypt prueft Domain-Besitz via HTTP-01 Challenge
C
Zertifikat wird als K8s Secret gespeichert — Traefik nutzt es
D
Automatische Erneuerung 30 Tage vor Ablauf

ℹ Hinweise

TLS-Terminierung passiert bei Traefik — danach ist alles HTTP intern im Cluster. Das ist sicher, weil der Traffic den Server nie verlässt.

cert-manager erneuert Zertifikate automatisch alle ~60 Tage (Let's Encrypt: 90 Tage gueltig, Renewal 30 Tage vorher).
